SOLID ORNAMENT ENGINE



Tunnel



  



  



  



  



  



  



  



  



  



  


FUNNEL 0 = straight cylinder, all apparent shrink comes from
distance. Toward 1 the tunnel physically narrows and the scene flattens —
0.1–0.3 keeps real depth with a vortex read.



Ornaments





  



Branch Fractal



  



  



  



  



  



  



  



  



  


One contraction map applied over and over — the depth-3 cloud
is a scaled copy of the depth-2 cloud.


SELF-SIMILARITY decides whether a child inherits its parent's form and
ornament tile. At 1 the same shape recurs at every scale, which is what
actually makes a cluster read as fractal; at 0 every node is a different
random object and the recursion is still there mathematically but invisible.



The cascade also has to be big enough to SEE: contraction^depth sets the
smallest node, so 0.6 at depth 3 gives 1.00 / 0.60 / 0.36 / 0.22. Push
contraction down and the deep levels vanish into a few pixels.


Node count per wall position is (b^(d+1)−1)/(b−1) — watch the solids counter.



Cage





  



  



  







  



  



  




A polyhedral frame around the tunnel axis — ornaments at the
vertices, struts along the edges. It rides the same recursion as everything
else, so the cages nest and shrink into the light rather than sitting in
front of the scene as one static object.


RINGS BETWEEN thins them out; it is applied as a function of the ring
coordinate, not by skipping rings, so the loop stays seamless. CAGE TWIST
turns each successive cage so they interleave instead of stacking.


VERTEX FORM indexes into the current FORM SET, so it changes with the set.
GEODESIC 3V is 162 vertices and 480 struts per cage — watch the solids
counter.



Ribbons



  



  



  



  



  



  



  



  



  


Each ribbon is one continuous swept surface, not a chain of
cylinders — the vertex shader places every vertex directly on the helix, so
it bends smoothly with no joints or caps. The cross-section frame uses the
radial direction projected off the tangent, which never flips; a Frenet
frame would spin at inflections and twist the tube.


Wobble harmonics and beads-per-ring are integers so every sub-tier's period
divides one ring — otherwise the fly-through pops on each wrap.




  



  


RIBBON SHAPE sets the cross-section: a bar has flat faces with
hard edges instead of a round tube.


HARD ANGLES bends the path itself. 0 is the smooth snake. Above that the helix
becomes a polygon with that many corners per ring — straight runs meeting at
sharp mitres, like bent pipe. Low values (3–6) give long angular sweeps; high
values approach the curve again. It is a whole number per ring because any
other spacing breaks the seamless loop.



Ornament Print



  



  



  


16 ornament tiles — mandalas, dot rings, eyes, scales,
paisley, filigree — drawn to a texture at load and printed onto the solids.


Keep TILES AROUND / ALONG at 1 unless the form is large on screen.
Repeating a motif several times across a small form just means each copy
lands on a few pixels, the mip chain averages it to the tile's ground
colour, and the whole thing turns to mud. One motif per form is also what
the references do — each dome carries a single mandala.



Material





  



  



  





  



  



  


Banding is evaluated in each form's own object space, so the
pattern wraps the solid instead of sliding across it.



Light



  



  



  



  



  



  



  



  



  



  



  



  



Copies



  



  



  



  



  



  



  



  



  




Each copy is the WHOLE structure again — every ring, ribbon and
fractal cluster — rigidly placed with its own offset, turn and scale. They
share one depth buffer, so where two vortexes intersect they genuinely cut
through each other.


Copy 1 is the base; the sliders above edit whichever copy is selected. Turn a
copy 90° on Y and its tunnel bores sideways through the first one. Cost is
linear: 4 copies is 4× the triangles.



Orientation



  



  



  



  



  



  



  



Drag the canvas to tilt and turn — it writes back into X and Y,
so the sliders and the mouse never disagree.


PIVOT 0 rotates the view in place: the camera is on the tunnel axis, so past
about 30° the tunnel swings out of frame and you see the void behind it.
Raise PIVOT and the camera orbits a point that far down the tunnel instead,
so the structure tumbles while staying framed. Both agree exactly at zero
rotation, so moving PIVOT on its own changes nothing.



Camera & Motion



  



  



  


TUNNEL SPIN rotates the ornaments around the tunnel axis —
it is structural, not a camera move. Because the rings are geometric the
fly-through loops seamlessly.



Occlusion



  



  



  



  



  



  


Screen-space ambient occlusion darkens where forms meet. With
thousands of solids overlapping, nothing else tells you which one is in front
— without it everything floats in the same evenly lit soup.


RADIUS is in world units: small values catch the crevices between touching
ornaments, large ones shade whole clusters. Raise BIAS if flat surfaces
self-shadow into stripes. SAMPLES trades noise for speed and BLUR cleans up
what is left; at 0 you can see the raw sampling pattern.


Set STRENGTH to 0 to skip both passes entirely. Setting
window.__dbgMode = 10 in the console shows the AO buffer on its
own, which is the quickest way to tune RADIUS and BIAS.



Video











  



  



  







Frames are rendered one at a time and pushed to the encoder by
hand, so a slow scene makes the export take longer but never stutters in the
file — the clip always plays at the chosen rate.


The tunnel is periodic in phase, so one loop is seamless by construction.
PERFECT LOOP extends that to motion: it rounds TUNNEL SPIN and each SPIN axis
to whole turns over the clip, and drives the fly-through from the frame index
rather than FLY SPEED. Turn it off to record exactly what is on screen.


MP4 records in Chrome, Edge and Safari. Firefox has no MP4 encoder, so AUTO
falls back to WebM there.
